## 2. 📖 Explanation

Text-to-image generation is an Artificial Intelligence technology that converts natural language descriptions into images.

AI image generation tools use prompts to understand the user's requirements and generate corresponding visual outputs.

In this experiment, two reference images are selected and analyzed based on their objects, colors, textures, lighting, background, composition and artistic style.

Different prompts are created, starting from simple descriptions and gradually adding more details to improve the generated images.

## 6. ⚙️ Procedure

1. Select two reference images for reproduction.
2. Examine the objects, colors, lighting, textures and background.
3. Write a basic prompt describing each image.
4. Refine the prompts by adding more visual details.
5. Identify the artistic style and composition.
6. Enter the refined prompts into an AI image generation tool.
7. Generate the images.
8. Compare the generated images with the original references.
9. Identify differences and modify the prompts.
10. Save the final generated images and document the results.
